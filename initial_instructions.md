The user will ask you to implement a specific feature. Before doing so, here are things to remember:

1. Look through the existing code and deeply understand it
2. Look through past branches and create a branch whose name is relevant to the feature (Once the user tells you what to implement)
3. Before you actually write the feature, create a quick skeleton + mention what files you're going to change
4. Create a test plan
5. Run the existing test suite to establish a baseline before touching anything
6. Code up the solution
7. Code up tests
8. Run tests and fix the code until all tests pass — if a test itself is wrong (not the code), fix the test and note why
9. If there are any additional code quality checks relevant to the project (e.g. radon for Python, linting, mise scripts), run those as well
